# Athena Reader

Free, offline-first reader for your own EPUB, PDF, Word and TXT files.

- Listen with system text-to-speech
- Highlights & notes export to Markdown (Obsidian / Notion friendly)
- Sync across iPhone, iPad, Android, web and Windows
- Ask cited AI questions across a book, a shelf or your whole library (AI needs a connection; always check the cited source)

No bookstore — it reads the files you already own.

Website: https://athena-reader.com/
